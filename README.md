# Gabriel Bao — Field Notes

一页式个人网站。所有视觉元素由 HTML、CSS 和本地 SVG 构成，没有外部字体、图片、统计脚本或表单。

## GitHub Pages

将本目录内容放在 `GabrielBao/GabrielBao.github.io` 仓库的 `main` 分支根目录，在仓库 Settings → Pages 中选择 **Deploy from a branch**、`main`、`/(root)`。网站地址为 `https://gabrielbao.github.io/`。

## 内容原则

页面只使用 GitHub 用户名和概括性的兴趣方向，不展示学校、雇主、具体地点、私人联系方式或未经确认的项目成果。
